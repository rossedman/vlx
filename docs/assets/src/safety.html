Safety model

Every call is classified, then gated

1 · CLASSIFY — first match wins
config overrides
safety.read / write / danger globs
built-in table
every io.systemd.* method, v257–v262
verb heuristics
Get·List·Describe → READ, Kill·Remove → DANGER
otherwise WRITE
unknown is never assumed safe
2 · CLASS
READ
no side effects
WRITE
changes state · all oneway calls
DANGER
disruptive or hard to undo
3 · POLICY
sent immediately — in every mode
read-only (default) → refused, exit 4
--allow-writes → confirm y/N (or --yes)
read-only (default) → refused, exit 4
--allow-writes → type the method name (or --yes)
Parameters are validated against the IDL before the gate · strings from services are stripped of escape sequences · secrets are redacted on screen
